• Синяя кнопка «Карта» из макета закреплена на любой глубине скролла. Это главный рычаг для CR SERP → Map: сейчас вход пропадает после первого экрана.
  • Тап по одиночному пину → компактная карточка в стиле карточки выдачи: листаются фото, рейтинг и отзывы, цена за 3 ночи / 2 гостей, ♡. В макете есть только сценарий с группой.
  • Тап по группе → шторка «N доступных вариантов в этой точке», как в макете.
  • Связь со списком: сдвинул карту → на «Список» сразу число отелей в кадре, список показывает только их.
  • Избранные отели отмечаются на пине (состояние пина с прода).
